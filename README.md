# Silk Way Star — подписной календарь

Календарь игр Silk Way Star в чемпионате SWHL 2026/27.

- Подписка: https://sibek.github.io/silk-way-star/silk-way-star.ics
- Источник: https://swhl.ru/tournament/1067241/calendar
- Время игр: московское (Europe/Moscow); в файле используется UTC для корректного отображения в любом часовом поясе.
- Длительность: приблизительно 2 часа, поскольку источник сообщает только время начала.
- Напоминание: за 1 час до начала игры. Некоторые приложения могут игнорировать напоминания подписных календарей или использовать собственные настройки.
- Автоматическая проверка источника каждые 6 часов через GitHub Actions. Календарное приложение проверяет подписку по своему расписанию.
- Переносы обновляют существующие события благодаря постоянному UID матча. SEQUENCE увеличивается только при изменении данных.
- При недоступности источника, ошибке разбора или исчезновении матча сохраняется последний рабочий календарь; workflow сообщает ошибку. Исчезновение матча требует ручной проверки, чтобы временно неполная страница не удалила игры из подписки.

## Подписка

В календарном приложении выберите подписку на календарь по URL и вставьте HTTPS-ссылку выше. Скачать и импортировать файл — отдельная операция без будущих обновлений.

Для Apple Calendar также доступна ссылка:
webcal://sibek.github.io/silk-way-star/silk-way-star.ics

## Обновление

```sh
python3 update_calendar.py
```

Для сохранённой страницы: `python3 update_calendar.py --html /path/to/calendar.html`.

Публикуется только содержимое `public/`. В репозитории нет учётных данных или частных данных.
