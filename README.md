# Silk Way Star - Игры

Календарь игр Silk Way Star в чемпионате SWHL 2026/27.

- Подписка: https://sibek.github.io/silk-way-star/silk-way-star.ics
- Источник: https://swhl.ru/tournament/1067241/calendar
- Название календаря: Игры. Названия событий используют обычный дефис: Silk Way Star - ХК Физрук.
- Время игр: московское (Europe/Moscow); DTSTART/DTEND используют TZID=Europe/Moscow с определением VTIMEZONE. UTC остаётся только в технических отметках обновлений.
- Сведения события пустые. Ссылка на матч указана только в поле URL.
- Адрес арены: улица Крылатская, 2 с5 Москва, Россия, 121552. GEO и X-APPLE-STRUCTURED-LOCATION задают точку на карте для Apple Calendar.
- Длительность: приблизительно 2 часа 30 минут, поскольку источник сообщает только время начала.
- Напоминание: за 2 часа до начала игры. Некоторые приложения могут игнорировать напоминания подписных календарей или использовать собственные настройки.
- GitHub Actions публикует обновления после загрузки изменений в репозиторий. Календарное приложение проверяет подписку по своему расписанию.
- Переносы обновляют существующие события благодаря постоянному UID матча. SEQUENCE увеличивается только при изменении данных.
- При недоступности источника, ошибке разбора или исчезновении матча скрипт останавливается и сохраняет последний рабочий календарь. Исчезновение матча требует ручной проверки, чтобы временно неполная страница не удалила игры из подписки.

## Подписка

В календарном приложении выберите подписку на календарь по URL и вставьте HTTPS-ссылку выше. Скачать и импортировать файл — отдельная операция без будущих обновлений.

Для Apple Calendar также доступна ссылка:
webcal://sibek.github.io/silk-way-star/silk-way-star.ics

## Обновление

Расписание обновляется только по запросу пользователя в этом чате, например: «Обнови календарь игр». Автоматическая проверка SWHL отключена; фоновые задания на Mac и RPi не установлены. После обновления публикуется файл по прежнему адресу, и календарные приложения подписчиков получают изменения при следующей проверке подписки.

Проверка 2 октября 2026: SWHL отвечает HTTP 468 на запросы с Linux и macOS runners GitHub. С Mac владельца источник доступен. Поэтому автоматическое получение изменений непосредственно с GitHub не подтверждено.

С Mac обновить и опубликовать календарь можно командой `bash publish_update.sh`.

```sh
python3 update_calendar.py
```

Для сохранённой страницы: `python3 update_calendar.py --html /path/to/calendar.html`.

Публикуется только содержимое `public/`. В репозитории нет учётных данных или частных данных.
